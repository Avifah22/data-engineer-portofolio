# Data Engineer Portfolio 🚀

Selamat datang di repositori portofolio saya! Repositori ini berisi kumpulan proyek di bidang **Data Engineering**, yang mendemonstrasikan kemampuan saya dalam membangun *data pipeline*, melakukan pemrosesan data, manajemen basis data, hingga *data serving* untuk kebutuhan sistem yang handal.

1. 🍫 Data Serving & REST API Development — Chocolate Sales (2026)

Deskripsi: Menerapkan konsep Data Serving dengan membangun REST API berbasis FastAPI untuk melayani hasil pemrosesan dan prediksi klasterisasi data penjualan cokelat secara real-time.
Tech Stack: Python, FastAPI, Uvicorn, Pandas, Pydantic, Scikit-Learn, Joblib.
Fitur Utama:
- Data Serving: Membangun endpoint REST API interaktif dan performa tinggi untuk konsumsi data real-time.
- Data Validation: Menggunakan Pydantic untuk melakukan skema validasi tipe data pada request payload sebelum diproses.
- Model Integration & Pipeline: Memuat artifacts model (.pkl) dan mengintegrasikan pipeline pemrosesan data (Pandas) ke dalam alur eksekusi API.
